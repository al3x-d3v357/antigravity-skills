## What I Do

Analyze the search intent behind any keyword and produce a complete SEO content brief — content type, format, angle, required sections, and semantic keywords — so the content you create actually matches what Google rewards.

## The 4 Intent Types

| Intent | What the searcher wants | Signal words |
|---|---|---|
| **Informational** | To learn something | "what is", "how to", "why", "guide" |
| **Navigational** | To find a specific site/page | Brand names, "login", "official" |
| **Commercial** | To research before buying | "best", "vs", "review", "top" |
| **Transactional** | To buy or take action | "buy", "price", "free trial", "download" |

## Content Modifiers

Beyond intent, every keyword has a dominant format in the SERPs:

- **List post** — "10 best X", "7 ways to Y"
- **How-to guide** — Step-by-step instruction
- **Comparison** — "X vs Y", "best tools for Z"
- **Definition** — "What is X"
- **Landing page** — Product/service page (transactional)
- **Case study** — Story + proof
- **Tool/Calculator** — Interactive resource

## Process

```
1. IDENTIFY    -> Determine the primary intent type for the keyword
2. FORMAT      -> Identify the dominant content format in top results
3. ANGLE       -> Find the unique angle that differentiates from existing content
4. OUTLINE     -> Build the content structure (H1, H2s, H3s)
5. SEMANTICS   -> List related terms and LSI keywords to include
6. BRIEF       -> Output full content brief with all specs
```

## How to Trigger

```
"Analyze the SEO intent for: [keyword or topic]"
"Create a content brief for ranking on [keyword]"
"What type of content should I create to rank for [keyword]?"
```

## Rules

- Never recommend a content type that does not match the dominant SERP format
- Always identify the angle that makes the content worth creating (not just another version of what's already ranking)
- Flag keywords where intent is mixed or ambiguous — these need careful positioning
- If web search is available, use it to verify actual top results before producing the brief

## Edge Cases

**High-competition keywords**: Flag that the brief is based on intent analysis, not a ranking guarantee. Suggest targeting longer-tail variants as an entry point.

**Local intent**: If the keyword has local modifiers ("near me", city names), flag this as local SEO — different strategy applies.

**Featured snippet opportunity**: If the keyword likely triggers a featured snippet (definitions, "how to"), note this and structure the H2/H3 answer blocks accordingly.
