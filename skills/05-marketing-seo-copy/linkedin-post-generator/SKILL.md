## What I Do

Draft LinkedIn posts that use proven engagement patterns — personal story hooks, demo formats, relatable pain points — adapted to LinkedIn's professional audience and algorithm.

## The Process

```
1. HOOK      -> Identify the best hook type for the topic
2. STRUCTURE -> Apply the LinkedIn post framework
3. DRAFT     -> Write in authentic, non-corporate voice
4. CHECKLIST -> Verify against pre-post checklist
```

## What Works (High Engagement)

| Pattern | Example | Why It Works |
|---|---|---|
| **Personal story hook** | "I always wished this existed" | Creates emotional connection |
| **Demo/Show format** | Video + screenshots | Visual proof > claims |
| **Relatable pain point** | "Download PDF, read it, find bank details..." | Audience nods along |
| **Before/After transformation** | Old way vs new way | Clear value proposition |
| **Casual, direct language** | "No login. No dashboard." | Feels authentic, not corporate |

## What Doesn't Work (Low Engagement)

| Anti-Pattern | Why It Fails |
|---|---|
| Generic product description | No hook, no story |
| Feature lists without context | No emotional resonance |
| Corporate tone ("We're excited to announce...") | Feels like an ad |
| Text-only posts with no visual | Scroll-past material |

## Hook Types (Ranked by Performance)

1. **Demo/Show** — Highest reach when done well
2. **Bold Claim** — Can go viral but risky
3. **Personal Story** — Consistent, reliable performer
4. **Question** — Good engagement, lower reach
5. **List** — Works with visuals, fails without

## Post Structure

```
[Hook — 1-2 lines that stop the scroll]

[Context — Why this matters / the problem]

[Insight or solution — What you built/learned]

[Proof — Demo, screenshot, or specific example]

[CTA — Soft ask, not salesy]
```

## LinkedIn-Specific Rules

1. **First line is everything** — Only ~150 chars show before "see more"
2. **Line breaks = readability** — Use them liberally
3. **Bullet points work** — But don't overdo it
4. **Tag sparingly** — Only if genuinely relevant
5. **Hashtags at the end** — 3-5 max, never in the body
6. **Video > Image > Text** — Always push for a visual

## Tone Guide

| Avoid | Use Instead |
|---|---|
| "We're excited to announce" | Lead with the thing itself |
| "Innovative solution" | Describe what it actually does |
| "Leverage synergies" | Plain language only |
| Emoji overload | 1-2 max if any |

## Templates

### Video Teaser Post
```
[Personal hook about the problem]

I do most of my work in [X] interfaces:
- [Tool 1]
- [Tool 2]
- [Tool 3]

But [specific task] still felt stuck in [year].

[Describe the old painful way — be specific]

So I built something different.

[Describe the new way — focus on simplicity]

No [friction]. No [friction]. Just [simple action].

Full demo dropping soon. Here's a preview 👇

[Video/Image]
```

### Product Demo Post
```
[Bold claim or question hook]

[1-2 sentences of context]

Here's how it works:

1. [Step 1 — user action]
2. [Step 2 — what happens]
3. [Step 3 — outcome]

That's it.

[Why this matters]

[Soft CTA]
```

### Behind-the-Scenes Post
```
For the past [time period], I've been [doing X].

The problem: [specific pain point]

What I tried:
- [Approach 1] — didn't work because [reason]
- [Approach 2] — got closer but [limitation]
- [Approach 3] — this is the one

[What you learned]

[Optional: what's next]
```

## Pre-Post Checklist

- [ ] First line hooks — would YOU stop scrolling?
- [ ] Personal angle — not corporate voice
- [ ] Specific details — not generic claims
- [ ] Visual attached (video > image > carousel > text)
- [ ] Soft CTA — not salesy
- [ ] Line breaks for readability
- [ ] Under 3,000 characters (LinkedIn limit)

## Anti-Patterns to Avoid

**The Corporate Announcement**: "We're excited to announce our new AI-powered platform! This innovative solution streamlines operations." → No hook, no specifics, no reason to care.

**The Feature Dump**: Listing features without a story or "so what?" → Reads like a press release, not a person.

**The Humble Brag**: "Just hit 10,000 users! So grateful!" → Self-congratulatory, zero value for the reader.
