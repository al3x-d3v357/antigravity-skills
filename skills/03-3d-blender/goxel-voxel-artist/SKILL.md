# Goxel Voxel Artist Skill

Esta skill permite criar, parametrizar e esculpir modelos 3D em **Voxel Art** utilizando o software **Goxel (0.15.1)** diretamente pelo servidor MCP `goxel-voxel-art` ou via CLI em segundo plano.

## Ferramentas Disponíveis no MCP:
1. `goxel_create_character`: Cria personagens completos (Arqueiro, Tanque, Mago, Suporte).
2. `goxel_create_object`: Constrói armas (espadas, arcos, cajados, escudos), baús, poções e tochas.
3. `goxel_run_custom_script`: Roda scripts JavaScript procedurais dentro do QuickJS do Goxel.
4. `goxel_export_model`: Converte modelos para `.vox`, `.obj`, `.gltf` e `.png`.
5. `goxel_open_gui`: Abre a interface visual do Goxel na tela para edição manual interativa.
